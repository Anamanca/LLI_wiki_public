## 5. Khởi động lại project (cold-start procedure)

> Thứ tự này khớp với deployment order trong `k8s/AGENTS.md`. Nếu host vừa reboot, container `llm-wiki-control-plane` sẽ KHÔNG tự chạy (policy = `no`), cần start thủ công trước.

### Bước 0 — Nếu kind container không chạy (sau reboot)
```bash
docker start llm-wiki-control-plane
# đợi ~30s cho cluster sẵn sàng
kubectl wait --for=condition=Ready nodes --all --timeout=60s
```

### Bước 1 — Bật lại auto-start toggles (tùy chọn, nếu muốn boot tự động)
```bash
systemctl --user enable --now llm-wiki-socat-forward.service
# docker restart policy chỉ cần đổi lại nếu muốn kind tự restart sau crash:
# docker update --restart=on-failure llm-wiki-control-plane
```

### Bước 2 — Storage + dependencies (idempotent, có thể đã có sẵn)
```bash
kubectl apply -f k8s/namespace.yaml
kubectl apply -f k8s/configmap.yaml
kubectl apply -f k8s/secret.yaml
kubectl apply -f k8s/postgres/
kubectl apply -f k8s/redis/
kubectl apply -f k8s/minio/
kubectl apply -f k8s/backend/rbac.yaml   # RBAC cho backend
```

### Bước 3 — Load Docker images vào kind
> Ảnh phải có sẵn trong kind node trước khi pod start (`imagePullPolicy: IfNotPresent`).

```bash
# Nếu đã có image trên host (kiểm tra: docker images | grep -E "backend|worker|frontend"):
docker images | grep -E "^(backend|worker|32_llm_wiki_clean_arch-frontend) "

# Nếu thiếu → build lại (BẮT BUỘC --network=host):
docker build --network=host -t backend:latest .
docker build --network=host -t worker:latest .
docker build --network=host -t 32_llm_wiki_clean_arch-frontend:latest frontend/

# Load vào kind:
kind load docker-image backend:latest --name llm-wiki
kind load docker-image worker:latest --name llm-wiki
kind load docker-image 32_llm_wiki_clean_arch-frontend:latest --name llm-wiki
```

## 6. Sau khi restart — Sync code (nếu đã sửa source)

> HostPath chain (chi tiết trong `k8s/AGENTS.md`):
> Host `src/` → kind node `/code/backend-src/` → pod `/app/src/`
>
> Nếu sửa file `.py` trong `src/`, **bắt buộc** copy sang kind node trước rồi mới restart pod, nếu không pod sẽ load code cũ.

```bash
# Copy thay đổi:
docker cp src/llm_wiki/<path-to-file>.py \
  llm-wiki-control-plane:/code/backend-src/llm_wiki/<path-to-file>.py

# Restart cả 3 deployment mount cùng hostPath:
kubectl -n llm-wiki rollout restart deploy/backend-v2
kubectl -n llm-wiki rollout restart deploy/cpu-worker
kubectl -n llm-wiki rollout restart deploy/wiki-consumer
```

Nếu sửa `pyproject.toml` hoặc `Dockerfile` → rebuild + load image + restart (xem `k8s/AGENTS.md` mục "Deploy After Code Changes").

Nếu sửa `frontend/**/*.{tsx,ts,css}` → rebuild frontend image + restart deploy `frontend` (frontend KHÔNG có hostPath, là standalone build).
